# Workflow DAI

1. Captura: registrar fatos/impedimentos do ciclo atual.
2. Triagem: classificar em `Dominio`, `Arquitetura`, `Infra`, `Dados`.
3. Decisao: registrar no DAI; se estrutural, abrir ADR.
4. Execucao: implementar com criterio de aceite.
5. Verificacao: validar com teste/evidencia/documentacao.
6. Encerramento: atualizar status e resultados.

## SLA sugerido
- Critico: 24h
- Alto: 72h
- Medio: 5 dias uteis
- Baixo: proxima iteracao
