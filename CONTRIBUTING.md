# Contributing to LabGP

Thanks for helping improve LabGP.

## Scope
LabGP is a C++ project for research project management, with emphasis on:
- explicit project registration
- manual selection of source documents
- domain rules, UI flows, and quality metrics
- traceable governance artifacts

## Working style
- Keep changes small and focused.
- Prefer explicit domain behavior over hidden automation.
- Avoid broad refactors unless they unblock a concrete goal.
- Preserve the manual-curation flow when touching inventory or project setup.

## Before opening a change
- Run the relevant build and tests.
- Update documentation only when it describes real behavior.
- Keep commits and pull requests easy to review.

## Review expectations
- Changes that affect domain rules should include tests.
- Changes that affect workflow or governance should include a short rationale.
- UI changes should keep the existing project language and layout consistent.

## Reporting issues
Include:
- what you were trying to do
- what you expected
- what happened instead
- relevant logs, screenshots, or file paths

## Contact
For coordination and ownership, open a discussion or mention the repository owner in the code review.
